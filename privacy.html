Privacy policy

Last updated: November 23, 2026

This policy covers a personal setup of rclone that connects to the owner's own Google Drive. It is used only by its owner and is not offered to the public.

What access the app requests

When the owner signs in with Google, the app asks for permission to view and manage files in their Google Drive. This is used so rclone can list, upload, download, copy and sync files when the owner runs an rclone command.

What data is collected

None. The app has no server and no database. Files move directly between the owner's computer and Google Drive.

Where credentials are stored

The sign-in token that Google issues is stored only in rclone's configuration file on the owner's own computer. It is never sent to anyone else.

Sharing and selling data

Google user data is not shared with, sold to or transferred to any third party, and it is not used for advertising.

Google API Services User Data Policy

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account permissions page. Deleting rclone's configuration file from the computer also removes the stored token.
